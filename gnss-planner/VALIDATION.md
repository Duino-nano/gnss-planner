# 初版の検証記録

実施日：2026-10-08（JST）。Node.js v24.19.0、Windows上で実施。

## 計算

- `node --test test/*.test.mjs`：9件成功。
- 正四面体配置の解析解 PDOP=1.5 と照合。
- 独立システム時計差、単独衛星システムの寄与、ランク不足、衛星数不足を確認。
- 地平座標の東・北・天頂、WGS84高さのm→km換算を確認。
- SGP4をVallado AIAA 2006-6753の00005検証ケースの基準座標と照合。許容差1e-5 km。
- `node scripts/compare-gps.mjs`：GPS Yumaアルマナックから別途実装したケプラー軌道計算と、GP/SGP4による見通し方向を比較。東京駅付近、現在と±24時間、採用範囲内87件、最大角度差0.012952°、平均0.005472°（2026-10-08 16:56 JST時点）。異なるデータ・モデルの比較であり、実際の衛星位置に対する測定誤差ではない。
- 最初の比較では3日を超えて古いG25に最大約2.05°の差を確認したため、全系統で軌道の採用上限を7日から3日に短縮。除外数を画面表示し、古いデータを計算対象に残さない方針に変更。

- 物理スマートフォンでの位置情報取得・追従、証明書インストール、LANのファイアウォール越しの接続は未検証。PC側のHTTPS応答までは検証済み。
